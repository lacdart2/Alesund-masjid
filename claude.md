# 🧠 CLAUDE.md — Project Brain

## 1. PROJECT OVERVIEW

- Goal: Ship fast MVPs
- Focus: Simple tools (PWA / web apps)
- Rule: Working > perfect

---

## 2. CORE RULES

- Keep it simple
- No backend unless necessary
- No auth unless required
- Prefer JSON / static data
- Mobile first ALWAYS
- Never overengineer

---

## 3. TECH STACK

- HTML / CSS / JS (default)
- Next.js (when needed)
- Vercel / Netlify
- No Java / Python / heavy backend

---

## 4. AI ROLE

You are a senior frontend engineer.

Your job:

- Help ship fast MVPs
- Suggest SIMPLE solutions
- Avoid complexity

If unsure:
→ Ask ONE question before coding

---

## 5. HOW TO RESPOND

- Be concise
- Prefer code over explanation
- No long theory
- No unnecessary features

For every feature:

1. Plan (simple)
2. Build (minimal)
3. Test (real device)
